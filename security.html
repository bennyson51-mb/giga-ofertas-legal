Seguranca da Informacao

Ultima atualizacao: 5 de outubro de 2026.

O GIGA Ofertas e uma automacao privada de afiliados e publicacao, executada por fluxos automatizados no GitHub Actions e integrada apenas por APIs oficiais das plataformas utilizadas.

Credenciais e acesso

  • Chaves, tokens e segredos de API sao armazenados em GitHub Actions Secrets e nao sao incluidos no codigo-fonte publico ou privado.
  • Os workflows usam permissoes minimas necessarias, com acesso de leitura ao repositorio quando possivel.
  • Credenciais do TikTok Shop sao utilizadas apenas no ambiente de execucao da automacao e para as finalidades autorizadas.

Dados tratados

  • O sistema nao solicita nem armazena senhas de usuarios do TikTok Shop, documentos de identidade, dados bancarios ou dados de cartao.
  • O processamento se limita a dados necessarios para selecionar produtos, operar colaboracoes de afiliados, preparar/publicar conteudo e registrar metadados tecnicos de execucao.
  • Dados obtidos por APIs nao sao revendidos nem compartilhados para finalidades alheias ao servico.

Controles operacionais

  • O repositorio principal possui verificacao automatizada contra segredos comprometidos e validacao de codigo em pushes e pull requests.
  • Dependencias sao acompanhadas por atualizacoes automatizadas.
  • Tokens podem ser revogados ou rotacionados a qualquer momento no provedor correspondente.
  • Falhas de seguranca ou suspeita de exposicao de credenciais exigem revogacao/rotacao imediata e revisao dos logs de execucao.

Retencao e exclusao

O GIGA Ofertas mantem apenas o minimo necessario para a operacao, como historico de produtos/publicacoes e metadados tecnicos. Tokens de acesso sao mantidos somente enquanto a integracao permanecer autorizada e podem ser revogados. Dados associados ao servico podem ser eliminados quando a integracao for encerrada ou quando houver solicitacao aplicavel.
