Política de Privacidade

Última atualização: 5 de outubro de 2026.

O GIGA Ofertas não solicita cadastro próprio, senha, documento ou dados bancários dos usuários.

Integrações oficiais, como TikTok, Telegram, Shopee, GitHub Actions e programas de afiliados, podem tratar dados técnicos necessários para operar suas próprias plataformas.

Links de afiliado podem conter identificadores de campanha ou parceiro para atribuição de comissões e medição de resultados.

O acesso a credenciais e tokens é restrito segundo o princípio do menor privilégio, com armazenamento em mecanismos de segredo como GitHub Actions Secrets. Segredos não são publicados no código.

Dados confidenciais são transmitidos apenas por conexões HTTPS/TLS fornecidas pelos serviços integrados. Dados persistentes mantidos pelo projeto devem permanecer em serviços que ofereçam proteção em repouso.

O projeto mantém revisão periódica de dependências, verificação automatizada contra segredos expostos e controles de acesso compatíveis com a infraestrutura utilizada.

Solicitações válidas de acesso, correção ou exclusão de dados relacionadas ao projeto serão atendidas quando tecnicamente aplicável. Ao término da relação aplicável, dados sob controle do projeto serão excluídos ou anonimizados quando não houver obrigação legítima de retenção.

Incidentes de segurança suspeitos ou confirmados que afetem dados do TikTok Shop, vendedores ou usuários serão comunicados às partes afetadas e ao TikTok Shop pelos canais oficiais disponíveis, conforme aplicável.
